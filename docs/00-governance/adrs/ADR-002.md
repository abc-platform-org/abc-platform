# ADR-002 — In-salon, specialist-operated shared display

**Status:** `PROPOSED_FOR_REVIEW` | **Date:** 2026-10-28 | **Decision maker:** to assign at Gate-01

## Context

User explicitly rejects at-home customer app and auto-sending images.

## Proposed decision

Build shared consultation screen with privileged specialist/management boundaries enforced in backend.

## Consequences and tradeoffs

Streamlined salon flow; requires screen-privacy and user-role UX design.

## Alternatives still to assess

Consider minimal platform alternatives and vendor capability through a POC; no implementation is claimed by this decision document. No single provider is mandatory without benchmark evidence.

## Affected contracts

`AIS-001,PRD-019`; update relevant schemas, engine tests, migration map and risk register before marking this ADR accepted.

## Verification and exit

Demonstrate contract test(s), integration flow and negative/failure cases appropriate to this decision. Capture code SHA, test execution result, human reviewer and linked issue/PR; status remains PROPOSED until review.

## WP-000-02 — Shared-screen authority and privacy refinement (2026-10-29)
**Status remains `PROPOSED_FOR_REVIEW`.** Client and specialist physically together at one salon display. The authenticated specialist owns session operations and professional decisions. Client can express preferences and select a visual option in Shared View without acquiring specialist/admin permissions. No client home portal, remote preview delivery or public share as product default.
**Rejected:** separate customer self-service at-home surface (outside current scope); always-visible professional data drawer (privacy leak). **Required contracts:** shared vs specialist vs management visibility, consent by purpose, actor attribution, privileged drawer authentication, no unrelated personal notes on shared display; server-side tenant/role enforcement. **Tests:** forced-role/API bypass, screen-leak review, client chooses Look but no FZ-3, specialist unlock/lock, session interruption. **Affected:** MIG-09/13, AIS-001/024/025, PRD-002/019. **Approval:** Product/UX + Security/Privacy Authority.
