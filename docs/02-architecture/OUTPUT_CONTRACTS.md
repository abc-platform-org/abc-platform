|---|---|---|
| OUT-01 | Clarification / targeted question | Shared consultation |
| OUT-02 | Recommendation set | Studio look discovery |

| OUT-04 | Assessment of fixed user choice | Decision workspace |
| OUT-05 | Visual preview + honest approximation | Visual canvas |
| OUT-06 | Service explanation | Client and specialist |
| OUT-07 | Maintenance and aftercare | Shared session / professional plan |
| OUT-08 | Feasibility assessment | Professional review |
| OUT-09 | Safety notice | Shared/private view as policy permits |
| OUT-10 | Decision summary | Shared session |

| OUT-12 | Specialist analysis | Privileged workspace |

| OUT-16 | Relevant service bundle | Salon proposal |
| OUT-17 | Failure/recovery instruction | Appropriate interface |

## New, separately versioned output

`TECHNICAL_PLAN_DRAFT` and `SPECIALIST_VALIDATION` are new productization contracts beyond the historic 17. **Do not silently renumber the canonical OUT IDs**. These outputs are internal/professional unless a carefully scoped summary is rendered on the shared display.

All outputs carry `session_id`, `tenant_id`, `source_version_ids`, `evidence_scope`, `status`, `created_at` and `policy_decision` where applicable.
