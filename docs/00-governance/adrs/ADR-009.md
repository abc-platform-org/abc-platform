# ADR-009 — Durable event-oriented session workflow

**Status:** `PROPOSED_FOR_REVIEW` | **Date:** 2026-10-28 | **Decision maker:** to assign at Gate-01

## Context

Loss of conversation memory and asynchronous race conditions threaten state.

## Proposed decision

Backend persisted state machine, event/outbox, idempotent jobs, recoverable checkpoints.

## Consequences and tradeoffs

Infrastructure complexity; reliable replay and audit.

## Alternatives still to assess

Consider minimal platform alternatives and vendor capability through a POC; no implementation is claimed by this decision document. No single provider is mandatory without benchmark evidence.

## Affected contracts

`AIS-026,PRD-001`; update relevant schemas, engine tests, migration map and risk register before marking this ADR accepted.

## Verification and exit

Demonstrate contract test(s), integration flow and negative/failure cases appropriate to this decision. Capture code SHA, test execution result, human reviewer and linked issue/PR; status remains PROPOSED until review.

## WP-000-02 — Durability and event semantics refinement (2026-10-29)
**Status remains `PROPOSED_FOR_REVIEW`.** Session State Machine owned by backend; transactional event/outbox, checkpoint recovery, idempotent worker commands with correlation IDs, monotonic aggregate version and stale job result rejection. Exactly-once delivery should NOT be claimed for network events; enforce effectively-once business effects through idempotency and verified transactional boundaries.
**Decision impact:** ENG-01 controls workflow state; ENG-12 controls visual revisions but does not own global session; ENG-16 controls professional validation record; ENG-17/19 cannot mark transaction succeeded before domain acknowledgement. **Alternative:** browser-only or LLM-memory state rejected due to session loss and races. **Tests:** interrupted image job/recovery, duplicate event, out-of-order result, concurrent Look edit, failed business command compensation. **Approval:** Runtime/Architecture Authority and QA for failure evidence.
