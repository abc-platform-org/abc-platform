# Contributing to ABC

Use an issue → isolated branch → PR → CI tests → review → protected merge workflow. Source-of-truth requirements are in `/docs`; experimental notes cannot silently replace approved contracts. New AI engines need typed contract, negative tests, data provenance and performance/quality measurement. New beauty service packs need specialist approval and independent safety/QA gates. No customer images, health information or real credentials in commits. Use demo fixtures that contain no personal data. Attach actual test and commit evidence to every completed issue.
