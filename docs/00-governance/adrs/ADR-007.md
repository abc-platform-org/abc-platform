# ADR-007 — Feasibility is not visual quality

**Status:** `PROPOSED_FOR_REVIEW` | **Date:** 2026-10-28 | **Decision maker:** to assign at Gate-01

## Context

Visually fitting color/cut may be physically unsafe or impossible.

## Proposed decision

Separate feasibility result and professional checks from image QA.

## Consequences and tradeoffs

More cautious experience; safer service decisions.

## Alternatives still to assess

Consider minimal platform alternatives and vendor capability through a POC; no implementation is claimed by this decision document. No single provider is mandatory without benchmark evidence.

## Affected contracts

`AIS-021,PRD-013`; update relevant schemas, engine tests, migration map and risk register before marking this ADR accepted.

## Verification and exit

Demonstrate contract test(s), integration flow and negative/failure cases appropriate to this decision. Capture code SHA, test execution result, human reviewer and linked issue/PR; status remains PROPOSED until review.
